# Oasis LMF model files

Generated by `run_model.py` (`src/oasis_export.py`). CSV versions of the ktools model data.

| File | Content |
|---|---|
| `model_data/events.csv` | 10,000 stochastic event ids (one per simulated year) |
| `model_data/footprint.csv` | event_id, areaperil_id (= ERA5 cell), intensity_bin_id (5 mm rainfall bins), probability |
| `model_data/intensity_bin_dict.csv` | rainfall bins 0-400+ mm |
| `model_data/vulnerability.csv` | 6 vulnerability functions (3 occupancies x flood-prone / standard), with Beta secondary uncertainty discretised into damage bins |
| `model_data/damage_bin_dict.csv` | 22 damage bins (0, 20 x 5 %, 1) |
| `keys.csv` | lookup result: location -> AreaPerilID, VulnerabilityID per coverage (1 building, 3 contents, 4 BI) |

Exposure in OED format: `../data/exposure/istanbul_portfolio_OED_location.csv` and `..._account.csv`.

Convert to binaries (ktools), e.g.:
```
evetobin < events.csv > events.bin
footprinttobin -i 81 < footprint.csv
vulnerabilitytobin -d 22 < vulnerability.csv > vulnerability.bin
damagebintobin < damage_bin_dict.csv > damage_bin_dict.bin
```
Status: format follows the ktools CSV specifications. A full `oasislmf model run` has not been executed yet (roadmap).
